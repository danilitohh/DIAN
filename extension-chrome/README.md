# Extensión Chrome — Exógena DIAN

1. Abre `chrome://extensions`.
2. Activa **Modo de desarrollador**.
3. Pulsa **Cargar descomprimida** y selecciona esta carpeta `extension-chrome`.
4. Abre los detalles de la extensión y activa **Permitir acceso a URLs de archivo**; se usa para adjuntar el archivo descargado.
5. Regresa a la aplicación, recarga y pulsa **Abrir DIAN y descargar**.

La extensión no lee ni almacena usuario o contraseña. Solo empieza a actuar después de que la DIAN muestra el dashboard autenticado.
